# AngularNova - Modern Angular Showcase Website

A fast, sleek, and responsive modern website built with **Angular (v21)**, **TypeScript**, and **Angular Signals**.

## ✨ Features Included

- **⚡ Standalone Component Architecture**: Modern Angular without NgModules.
- **🔄 Fine-Grained Reactivity with Signals**:
  - Interactive live counter utilizing `signal()` and `computed()` derivations.
  - Interactive signal-driven task/planner board with status toggling and deletions.
- **🏷️ Dynamic Filtering**: Category-based feature filtering utilizing modern control flow (`@for`, `@if`).
- **📱 Responsive Glassmorphic UI**:
  - Sticky glassmorphic navbar with mobile toggle.
  - Hero section with live stat indicators.
  - Interactive demo playground.
  - Features showcase grid.
  - Newsletter subscription form with input validation and notifications.
  - Complete footer.

---

## 🚀 Getting Started

### 1. Run the Development Server
```bash
npm start
```
Navigate to `http://localhost:4200/` in your browser. The application will automatically reload if you change any of the source files.

### 2. Build for Production
```bash
npm run build
```
The build artifacts will be stored in the `dist/angular-app/browser/` directory.
